Falta configurar la base de datos.

Esta app ya no depende de Claude — usa una base de datos gratis en Firebase para que todos (desde cualquier navegador) vean lo mismo. Sigue estos pasos una sola vez:

1. Ve a console.firebase.google.com y crea un proyecto gratis.
2. En el menú, entra a Firestore Database → "Crear base de datos" → modo de prueba.
3. Ve a ⚙️ Configuración del proyecto → Tus apps → Agregar app web y copia el objeto firebaseConfig.
4. Pega esos valores en el archivo HTML, en la constante firebaseConfig (cerca del inicio del <script>), reemplazando los textos "TU_...".
5. Guarda el archivo y compártelo con tu familia — ya todos verán los mismos datos en tiempo real, sin pasar por Claude.
